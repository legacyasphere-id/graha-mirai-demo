This repository contains a **private concept pitch demo** prepared by **Legacya Sphere** for the **Graha Mirai** housing project in Kota Deltamas, Cikarang.

## Ownership & Copyright Disclaimer

- **Developer Logos:** Excluded from the user interface and repository. A plain-text wordmark (`Graha Mirai (concept)`) is used throughout the demo.
